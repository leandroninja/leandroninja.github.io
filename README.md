## Como rodar localmente

Não precisa de build — é HTML estático:

```bash
git clone https://github.com/leandroninja/leandroninja.github.io
cd leandroninja.github.io
# abrir index.html no navegador
```

Ou com live server (VS Code extension `ritwickdey.LiveServer`): botão direito em `index.html` → *Open with Live Server*.
